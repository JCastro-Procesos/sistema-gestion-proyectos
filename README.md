# ITM Group — Sistema Operativo de Gestión de Proyectos

Repositorio privado de pruebas.

## Probar

Abrir `index.html` en un navegador. Esta versión es un **prototipo mínimo** con iniciativas, tareas, RAID y exportación/importación JSON. Guarda los datos en `localStorage` del navegador.

## Seguridad

Usar únicamente datos ficticios. No existe autenticación ni sincronización entre usuarios. GitHub Pages no debe asumirse como un entorno privado.
